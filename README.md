# Balenciaga Pricing Pipeline

> **Status: Phase 5a – delivery gate (write-audit-publish) done; next: semantic layer + metrics agent.** This README is rewritten at the end of the project; the
> step-by-step build log lives in [`docs/`](docs/).

An analytics-engineering project that rebuilds a luxury price-monitoring pipeline with **dbt on Databricks**,
to fix a real production failure:

> Two deliveries with different cadences – a **weekly Micro** delivery (a client's hero products) and a
> **monthly Macro** delivery (category-level metrics) – shared **one mutable staging table**. Every import of a
> crawl overwrote that table for the whole source, so whoever imported last decided which crawl the other
> delivery saw. In practice an analyst finishing last week's Macro delivery and another analyst pushing this
> week's Micro delivery alternately re-imported last week's and this week's feed.

The fix is architectural, not procedural: an **append-only raw layer**, **deterministic dbt models**, and an
**as-of date** so Micro and Macro read different points in time from the same immutable history – proven by a
test that would have failed under the old design.

## Data

All crawl data in this repository is **synthetic** – generated by [`generator/`](generator/) and calibrated on
aggregate statistics of real crawls (price quantiles per category, cross-market price ratios, label
vocabularies). **Prices are not real Balenciaga prices.** The generator also plants ~35 kinds of dirty data
seen in real crawling work, and writes an answer key so the QA layer can be graded.

```bash
python3 -m generator.generate --seed 42 --out data        # ~240k rows, 15 files, ~30 s, no dependencies
python3 -m generator.validate --out data --determinism    # 13 self-checks
```

## Stack

| Layer | Tool |
|---|---|
| Storage + compute | Databricks (Free Edition) – Unity Catalog, Volumes, serverless SQL warehouse |
| Transformation | dbt (dbt platform, Studio IDE) with the `dbt-databricks` adapter |
| QA | dbt data tests, unit tests, `qa_*` models graded against the generator's answer key |
| Serving | Micro / Macro marts → metrics agent (governed SQL) + Evidence.dev dashboards |
| CI/CD + site | GitHub Actions → GitHub Pages |
